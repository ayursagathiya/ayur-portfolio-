03 / CASE STUDY

Airport Experience

Designing a comprehensive, high-fidelity wayfinding cockpit and flight departure dashboard system to streamline passenger navigation.

ROLE

Systems UX Lead Designer

TIMELINE

8 Weeks (2025)

DELIVERABLES

Terminal Dashboard UI, Mobile App

SYSTEM SCOPE

Wayfinding, Passenger Radar

The Challenge

Airports are stressful environments. Passengers are overloaded with visual noise: advertisements, announcements, changing gates, and confusing terminal maps.

Our task was to rethink terminal interfaces. The dashboard cockpit needed to display flight lists, terminal maps, gate status, walk times, and security checkpoints in a unified layout that reduces cognitive friction.

USER EMOTION GOAL

Transforming anxiety into calm through structured information grids, clear route mapping, and real-time security wait-time notifications.

Passenger Journey Blueprint

The Stress Points

1. Luggage Drop — Finding the correct desk quickly.
2. Security Queue — Unknown wait times make passengers anxious.
3. Gate Navigation — Unclear directions to remote boarding gates (e.g. Gate B-12).

The Solution Architecture

We constructed a radar wayfinding layout that updates the passenger's distance from their target gate relative to security clearance time. By displaying a simplified grid of departures next to an interactive terminal map, we eliminate the need to look back and forth at separate displays.

Terminal Dashboard Layout

Validated Metrics

  • 35% decrease in late gate check-ins during passenger testing groups.
  • Perfect clarity index score under visual noise tests simulating glare.
  • Highly praised wayfinding system by transit authorities.

Systems Design Lesson

When designing dashboards for large facilities, avoid visual details in maps. Instead, abstract terminals into interactive node networks (e.g. radar graphs). Abstract networks allow the user's eye to lock onto path highlights instantly, even while walking.
