04 / CASE STUDY

Sports Booking App

Designing a seamless multi-venue scheduling and community interaction application designed for local athletes to secure courts in seconds.

ROLE

Lead Product Designer

TIMELINE

5 Weeks (2025)

DELIVERABLES

Mobile UI, Prototype

LOCATION

Ahmedabad, India

The Challenge

Athletes looking to book courts face tedious booking processes: call confirmation lag, outdated web portals, and uncoordinated group payments.

We set out to create a unified mobile booking solution. The focus was to simplify checkouts, coordinate scheduling with team members, and show active slot availability across multiple venues in a local radius.

CORE KPI

Redesigning the booking funnel to support a checkout completed in under 3 taps, decreasing checkout drop-off rates.

Friction Points & User Journey

User Frustrations

Users expressed disappointment in reservation apps because calendar views are cluttered, displaying occupied time intervals and overlapping venue slots. We addressed this by building dynamic search filters that only query "active slots" matching specified sports and hour blocks.

The Booking Loop

1. Select Sport — Quick choice between Badminton, Football, Cricket, Tennis.
2. Time & Date — Horizontal scroll for hour slot selection.
3. Split Billing — Automatically invite teammates to divide reservation cost.
4. Confirm — Instant booking ticket generation with map coordinates.

Project Results

  • 30% boost in recurring reservations via teammate split-bill reminders.
  • Friction-free payment gateway integration yielding 94% transaction completion.
  • Highly praised UX structure validated during alpha trials in Ahmedabad.

Design Takeaway

Scheduling UX succeeds when it respects the user's focus. Rather than building a complex booking dashboard filled with options, we kept the screen layout focused on one action at a time: Sport → Date → Time → Pay. Linear pathways reduce processing overhead and improve user confidence.
